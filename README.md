# Unification Wars

A turn-based strategy game built in Godot (GDScript), currently in progress.

## About
Basically darkest dungeon's battle system without the dungeon crawling part of it (not implemented)

## Features
- Class hierarchy for characters, skills, and effects using inheritance and interfaces
- Extensible turn-based combat system

## Tech Stack
- Engine: Godot
- Language: GDScript

## Status
In progress — Two enemy types are available and two playable characters are available
